# Playbook: investigating a product with a high return rate

## Step 1: confirm the problem
- Return rate = units returned divided by units sold. Compare it with the company threshold and with similar products.
- A rate well above other products in the same category suggests a product-specific cause.

## Step 2: find the main reasons
- Group returns by reason and count units and refund value.
- If one or two reasons account for most returns, focus there.
- Related reasons that appear together (for example battery issue, charging failure and defective product) often share one root cause.

## Step 3: cross-check with customer feedback
- Read the comments and ratings of the same product. Recurring phrases confirm or contradict the return reasons.
- Evidence from independent sources (returns and feedback agreeing) raises confidence in a finding.

## Step 4: look at timing
- A rise in returns after a specific date can point to a new batch, a supplier change, a software update or a listing change.

## Step 5: write the conclusion
- State the most likely cause, the evidence (numbers and quotes), and a confidence level.
- If the data is not enough, say so and list what additional data is needed.
- Recommend concrete actions with an owner and priority, for example inspect the batch, contact the supplier, correct the listing.
